# NOVA-Q Specification v0.1

Universal Dragon = ecosystem

## Core Question
Can information be processed using atom-level quantum states instead of only classical 0 and 1?

## Concepts
- bit = 0 or 1
- qubit = probability state of 0 and 1
- superposition = mixed possibility state
- measurement = reading state, result becomes classical
- tunneling = quantum wave passing through a barrier probability
- entanglement = linked quantum states
- decoherence = quantum state disturbed by environment

## Direction
First build simulator.
Then build experiment model.
Then study real hardware paths:
- photon
- electron spin
- trapped ion
- superconducting circuit

## Rule
Do not fake quantum hardware.
Simulate first, understand deeply, then design physical experiment.
